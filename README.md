Student To-Do List Project
About the Project

The Student To-Do List is a simple web application built using HTML, CSS, and JavaScript. It helps students organize their daily tasks and manage their study schedules.

Features
Add new tasks.
Mark tasks as completed.
Delete tasks.
Display the number of remaining tasks.
Simple and user-friendly interface.
Responsive design for different screen sizes.
Technologies Used
HTML5 — Structure of the application.
CSS3 — Styling and layout.
JavaScript — Task management and interactivity.
Project Structure
Student-Todo-Project/
├── index.html
└── README.md

How to Run the Project
Download or extract the project folder.
Open the project folder.
Double-click index.html.
The application will open in your web browser.
Enter a task and click Add.
Use the checkbox to mark a task as completed.
Click Delete to remove a task.
Requirements
A web browser such as Google Chrome, Mozilla Firefox, or Microsoft Edge.
No internet connection or additional software is required.
Purpose

This project was created for learning basic web development concepts, including HTML structure, CSS styling, JavaScript functions, and DOM manipulation.
